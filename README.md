## Mise en ligne avec GitHub Pages

1. Créer un repository GitHub, par exemple `portfolio`.
2. Ajouter les fichiers du dossier.
3. Ajouter ton CV sous le nom `CV_Bahija_BenMohamed.pdf`.
4. Dans GitHub : Settings → Pages → Deploy from branch → `main` / root.
5. Ton portfolio sera accessible via l'URL GitHub Pages générée.
